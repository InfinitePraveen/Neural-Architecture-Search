# Contributing

1. Fork the repository.
2. Create a virtual environment and install `requirements.txt`.
3. Run the notebook from top to bottom.
4. Verify the Django demo starts.
5. Keep changes lightweight and CPU-friendly.

Useful contributions include better NAS search spaces, clearer notebook explanations, evaluation visualizations, Django UI improvements, and documentation.

Avoid adding large datasets, unnecessary modules, GPU-only dependencies, `src/`, or preprocessing packages.
